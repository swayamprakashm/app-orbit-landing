## 📖 About the Project

This repository contains the source code for the AppOrbit promotional landing page. It is designed to showcase the core features of the AppOrbit Android application, highlight its benefits for screen time management, and provide a direct portal for users to download the latest release.

### ✨ Key Features Highlighted
* **Usage Tracking:** Detailed insights into daily app consumption.
* **Parental Controls:** Tools to monitor and manage screen time for younger users.
* **Intuitive Dashboard:** Clean, easy-to-read analytics.
* **Direct Download:** Quick access to the latest `.apk` installation file.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
Make sure you have Git installed on your machine. If you are using Node.js for your environment, ensure you have `npm` or `yarn` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/swayamprakashm/app-orbit-landing.git](https://github.com/swayamprakashm/app-orbit-landing.git)
   ```

2.  Navigate into the project directory:
    ```bash
    cd app-orbit-landing
    ```
3.  Open `index.html` in your browser, or start your local development server (if applicable):
    ```bash
    # Example if using a package manager:
    npm install
    npm run dev
    ```

## 📦 Downloading the AppOrbit APK

**Important Note for Developers:** Due to GitHub's file size limits, the `AppOrbit.apk` (approx. 155 MB) is **not** tracked in this repository's version control.

To download the actual Android application:

1.  Navigate to the **Releases** section on the right side of this GitHub repository.
2.  Download the `AppOrbit.apk` file attached to the latest version tag.
